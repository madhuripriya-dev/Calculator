# Calculator

A simple calculator built using HTML, CSS, and JavaScript. It supports basic arithmetic operations and keyboard input.

## Features

* Addition, subtraction, multiplication, and division
* Decimal number calculations
* AC button to clear the display
* DEL button to delete the last digit
* Keyboard support
* Responsive layout
* Division by zero handling

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

calculator/
├── index.html
├── style.css
└── script.js

## How to Run

1. Clone or download this repository.
2. Open 'index.html' in your browser.
3. Start using the calculator.
